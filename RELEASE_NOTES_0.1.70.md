# MT Code 0.1.70 release notes

## Исправлено

- Баннер отклонённой отправки сменяется актуальным состоянием после нового запуска или новой ошибки. Исходный отказ ChatGPT sharing остаётся в истории.
- Исправлены React `#301` при возврате из настроек и цикл импортов в редакторе чата.
- Предупреждение Codex сохраняется в истории и больше не переводит успешный запуск в состояние `failed`.
- После `subscription_sharing_unsupported_capability` чат можно продолжить на обычном Codex или другом поддерживаемом маршруте.
- Кнопка «Не спать» рядом с режимами агента использует общую настройку среды и сочетается с выбранными режимами.
- Окно обновления и история релизов открывают личный форк Bony-Lord/mtcode.

## Проверено

- Из установщика Windows x64 проверены запуск, открытие черновика и сохранённого чата, а также возврат из настроек по Esc.

## Ограничения

- Переходы проверены в отдельном профиле. Общая проверка репозитория ограничена отсутствующими зависимостями mobile и marketing.
